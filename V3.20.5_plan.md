## Slice 3 - Decision Context Contract and Optional Bundle
### Scope
- Add typed handoff contract (e.g. `PolicyInput`/`DecisionContext`) so policy consumes canonical observation/learner outputs only.
- Require policy input derivation path:
  - `TaskInput -> ObservationOutput -> Prediction -> PolicyInput`
- Explicitly disallow:
  - policy reading raw experiment payloads directly
  - policy computing prediction error
  - policy mutating learner internals
- Add `PolicyBundle.step(...)` only if multi-stage policy flow is required.
- If bundle exists, enforce stage order and trace metadata.

### Implemented (this pass)
- Added typed decision-context transport contract:
  - `virtual_shaping_lab/vsl/agent/policy/input.py`
  - `PolicyInput`
- Added canonical policy-input derivation helper:
  - `build_policy_input(...)`
  - enforces typed derivation path:
    - `TaskInput -> ObservationOutput -> Prediction -> PolicyInput`
- Added boundary guardrails in decision-context contract:
  - rejects disallowed raw/boundary keys in policy metadata
  - keeps policy input free of raw task payload and error/update terms
- Updated selection operators to accept typed `PolicyInput` via `to_mapping()` transport compatibility.
- Exported decision-context APIs through package facades:
  - `virtual_shaping_lab/vsl/agent/policy/__init__.py`
  - `virtual_shaping_lab/vsl/agent/__init__.py`
  - `virtual_shaping_lab/vsl/__init__.py`
- `PolicyBundle.step(...)` intentionally deferred:
  - current policy execution remains single-operator and does not yet require multi-stage bundle orchestration.
