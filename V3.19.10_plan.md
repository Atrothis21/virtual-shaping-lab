# V3.19.10 Plan - Runtime Observation Adapter and Measurement Integration

## Objective
Route runtime observation construction through one canonical adapter seam, integrate agent/learner boundaries with finalized observation features, and expose observation traces in records/reporting.

---

## Entry Criteria
- V3.19.5 executable observation bundle and presets are merged and green.
- Runtime still has observation/feature normalization logic spread across helper paths.
- Record/report schema can accept metadata extension fields.

### Entry Criteria Status (Start of V3.19.10)
- V3.19.5 executable observation stack active: confirmed via `vsl/agent/observation/bundle.py` and `executable_presets.py`.
- Runtime still performs ad hoc learner-facing feature normalization: confirmed in `vsl/runtime/learner_adapter.py::_coerce_features_from_stimulus(...)`.
- No dedicated runtime observation adapter seam exists yet: confirmed no `vsl/runtime/observation_adapter.py` before this slice.

## Slices

## Slice 1 - Runtime Observation Adapter Seam
### Scope
- Add `vsl/runtime/observation_adapter.py`.
- Add APIs:
  - `RuntimeObservationAdapter`
  - `build_runtime_observation_adapter(...)`
- Normalize runtime stimulus/context payloads into deterministic observation bundle inputs.

### Implemented (this pass)
- Added canonical runtime observation adapter module:
  - `virtual_shaping_lab/vsl/runtime/observation_adapter.py`
- Added runtime observation APIs:
  - `RuntimeObservationAdapter`
  - `build_runtime_observation_adapter(...)`
- Added deterministic runtime normalization for stimulus/context payloads:
  - sequence-valued mapping entries -> one-hot cue presence
  - numeric mapping scalars -> keyed numeric features
  - non-numeric mapping scalars -> keyed presence (`1.0`)
  - inferred context from `context`/`context_state` when explicit context is not provided
- Exported runtime observation surfaces:
  - `virtual_shaping_lab/vsl/runtime/__init__.py`
- Added slice-1 runtime seam tests:
  - `tests/test_v3_runtime_observation_adapter.py`

### Commit
- `feat(runtime): add canonical runtime observation adapter seam`

## Slice 2 - Agent/Learner Boundary Integration
### Scope
- Ensure runtime/agent paths consume `ObservationOutput.features` as learner-facing input.
- Ensure learner adapter no longer reconstructs observation semantics from raw payloads when observation output is available.
- Preserve intermediate observation traces in runtime metadata.

### Implemented (this pass)
- Updated runtime learner adapter to accept finalized observation features directly:
  - `RuntimeLearnerAdapter.step(...)` now supports:
    - `observation_features`
    - `observation_feature_names`
    - `next_observation_features`
    - `next_observation_feature_names`
- Added precedence contract in learner seam:
  - when observation features are present, runtime raw-stimulus coercion is bypassed.
- Integrated runtime observation seam with rollout environment execution:
  - `CompiledProgramTestEnvironment` now materializes observation output through `RuntimeObservationAdapter`
  - learner stepping now consumes canonical observation features instead of ad hoc raw stimulus reinterpretation
- Preserved observation traces in runtime step metadata:
  - `metadata.observation.output` contains full observation output payload
  - `metadata.observation.measurements` contains observation-stage measurement snapshot
  - `metadata.learner.input_features` captures learner-facing feature mapping used at step time
- Added/extended runtime boundary tests:
  - `tests/test_v3_runtime_learner_adapter.py`

### Commit
- `refactor(runtime): route learner input through finalized observation output features`
