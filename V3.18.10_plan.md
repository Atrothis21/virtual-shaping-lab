# V3.18.10 Plan - Attention/Eligibility Extensions and Runtime Integration

## Objective
Add executable `A` and `E` operators, integrate learner execution into runtime via adapter seam, and expose learner internals to measurement/report pipelines.

---

## Entry Criteria
- V3.18.5 executable core (`P`, `Delta`, `W`, bundle step) is merged and green.
- Runtime has explicit attention state field from V3.18.0.
- Record schema supports extension fields without compatibility break.

---

## Slices

## Slice 1 - Attention Operators
### Scope
- Implement:
  - fixed attention
  - Pearce-Hall
  - Mackintosh (minimal explicit rule, documented)
- Ensure `A` modulates update inputs, not error semantics.

### Commit
- `feat(learning): add attention operators (fixed, pearce_hall, mackintosh)`

## Slice 2 - Eligibility Operators
### Scope
- Implement:
  - null eligibility
  - accumulating trace
  - optional replacing trace
- Document lifecycle: init, carry-over, reset behavior.

### Commit
- `feat(learning): add eligibility trace operators and lifecycle rules`

## Slice 3 - A/E-Aware Bundle and Presets
### Scope
- Extend bundle execution to optional A/E with null defaults.
- Add executable presets:
  - `pearce_hall_rw`
  - `mackintosh_rw`
  - `td_lambda`
- Add legality checks for A/E-dependent combinations.

### Commit
- `feat(learning): add A/E-aware executable presets and legality checks`

## Slice 4 - Runtime Adapter Seam
### Scope
- Add `vsl/runtime/learner_adapter.py` (or equivalent canonical seam).
- Route runtime trial loop learner execution through adapter.
- Remove duplicate direct learner execution branches from runtime path.

### Commit
- `feat(runtime): route learner execution through canonical learner adapter`

## Slice 5 - Measurement/Records Integration
### Scope
- Persist and expose `V`, `delta`, `theta`, `attention`, `memory` fields in rollout records.
- Ensure report generation can consume new traces without regressions.

### Commit
- `feat(reporting): expose learner internals in rollout records and measurement hooks`
