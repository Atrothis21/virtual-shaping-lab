# V3.21.10 Plan - Runtime Protocol Seam and Harness Integration

## Objective
Introduce one canonical runtime protocol adapter seam and route runtime harness execution through it while preserving the typed, causal experiment-agent boundary from `agent_protocol_interaction.md`.

Core causal order to enforce:
1. protocol emission (environment)
2. agent observe/predict/act (agent)
3. protocol consequence (environment)
4. agent learn (agent)
5. protocol advance/stop (environment)
