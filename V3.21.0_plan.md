# V3.21.0 Plan - Canonical Protocol Contract Ownership

## Objective
Establish one canonical symbolic protocol ownership surface and legality-first instantiation boundary under `virtual_shaping_lab/vsl/protocol`, aligned with the protocol-agent boundary rules:
- protocol/environment owns: emission, consequence, advance, stop
- agent owns: observe, predict, act, learn, advance_internal_time
- boundary contracts are narrow and typed (`TaskInput`, `Action`, `Outcome`, `TrialRecord`)
