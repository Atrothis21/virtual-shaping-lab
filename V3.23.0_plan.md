# V3.23.0 Plan - UI Preset Registry Bridge and Canonical Descriptor Ownership

## Objective
Establish a single V3-first UI preset discovery/descriptor bridge that consumes canonical backend preset contracts (policy/protocol/measurement) without introducing UI-owned semantics.

This plan is explicitly aligned to:
- `agent_protocol_interaction.md` (narrow typed causal boundaries)
- `V3.22.20_plan.md` closeout state (canonical measurement/runtime/report seams)
- existing policy/protocol/measurement registry + preset ownership surfaces

---

## Entry Criteria
- V3.22.20 merged and green.
- Canonical preset registries and preset expansion APIs are stable for:
  - policy
  - protocol
  - measurement
- Runtime/report trace promotion surfaces are stable and CI-guarded.
- UI run submission still uses canonical payload schema path only.
- No open blocker on preset-name or preset-hash stability.

### Entry Criteria Status (Start of V3.23.0)
- Canonical preset ownership is present and test-covered:
  - `virtual_shaping_lab/vsl/agent/policy/presets.py`
  - `virtual_shaping_lab/vsl/protocol/presets.py`
  - `virtual_shaping_lab/vsl/measurement/presets.py`
- Canonical registry payload/hash APIs are present:
  - policy/protocol/measurement registry modules
- Protocol-agent causal split is enforced in runtime architecture:
  - protocol owns `emit -> consequence -> advance -> stop`
  - agent owns `observe -> predict -> act -> learn`
- Measurement remains post-run and read-only over records.

## Slices

## Slice 1 - UI Preset Descriptor Contract
### Scope
- Add UI descriptor types/contracts for preset authoring surfaces.
- Define canonical descriptor shape referencing backend preset IDs only.

### Deliverables
- `UiPresetCatalog`
- `UiPresetDescriptor`
- `UiPresetFieldSpec`
- `UiPresetCompatibilityView`
- `UiRunPreview` (descriptor-level summary only)

### Implemented (this pass)
- Added canonical UI descriptor contract module:
  - `virtual_shaping_lab/ui/contracts/preset_descriptor_contract.py`
- Introduced typed UI contract surfaces:
  - `UiPresetCatalog`
  - `UiPresetDescriptor`
  - `UiPresetFieldSpec`
  - `UiPresetCompatibilityView`
  - `UiRunPreview`
  - `UiPresetDescriptorValidationError`
- Added deterministic identity helpers for descriptor/catalog payloads:
  - `to_dict()`
  - `to_json()`
  - `stable_hash()`
- Added validation helpers:
  - `validate_ui_preset_descriptor(...)`
  - `validate_ui_preset_catalog(...)`
- Enforced initial boundary-aligned legality constraints in descriptor validation:
  - classical presets require no policy preset (`none`)
  - operant/actioned presets require a non-`none` policy preset
  - classical action-space mode restricted to `classical_none` or null
- Added initial contract tests:
  - `tests/test_v3_ui_preset_descriptor_contract.py`

### Commit
- `feat(v3.23.0): add ui preset descriptor contracts`

## Slice 2 - Registry Discovery Adapters
### Scope
- Build adapters that materialize UI descriptors from canonical preset APIs.
- No hardcoded authoritative preset lists in page code.

### Deliverables
- policy/protocol/measurement discovery adapters
- deterministic descriptor generation from canonical names + payloads + hashes

### Implemented (this pass)
- Added registry-driven UI bridge module:
  - `virtual_shaping_lab/ui/contracts/preset_registry_bridge.py`
- Added canonical discovery adapters:
  - `discover_policy_presets()`
  - `discover_protocol_presets()`
  - `discover_measurement_presets()`
- Added descriptor/catalog materialization APIs:
  - `build_v3_ui_preset_descriptors()`
  - `build_v3_ui_preset_catalog()`
- Materialization behavior:
  - consumes canonical backend preset names/payloads/hashes
  - generates `UiPresetDescriptor` entries from UI preset registry IDs
  - attaches canonical backend hash references to descriptor metadata:
    - `backend_policy_hash`
    - `backend_protocol_hash`
    - `backend_measurement_hash`
  - carries boundary notes aligned to `agent_protocol_interaction.md`:
    - protocol owns environment stages
    - agent owns observe/predict/act/learn
    - measurement remains post-run and read-only
- Added Slice 2 bridge tests:
  - `tests/test_v3_ui_preset_registry_bridge.py`
  - validates canonical preset discovery parity
  - validates descriptor backend reference integrity
  - validates deterministic catalog hash generation

### Commit
- `feat(v3.23.0): add registry-driven ui preset discovery adapters`
