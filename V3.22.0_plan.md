# V3.22.0 Plan - Measurement Contract Ownership

## Objective
Establish canonical symbolic ownership for Measurement so it matches the hardened V3 pattern:
grammar -> validation -> registry/presets -> deterministic identity.

This plan is explicitly aligned to:
- `agent_protocol_interaction.md` (narrow typed boundary, causal split)
- `behavior_measurement.md` (measurement as phenomenon signature layer)
- `V3.22_plan.md` (measurement as first-class subsystem)

---

## Entry Criteria
- V3.21.20 merged and green.
- Runtime protocol seam and trace promotion are active.
- `TrialRecord` boundary is stable and includes protocol/policy trace surfaces.
- Measurement remains post-rollout and does not participate in runtime control loop.
- No open blocker in replay/hash stability from V3.21 closeout.
