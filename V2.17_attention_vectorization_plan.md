# V2.17 Attention Vectorization Plan

## Objective
Replace scalar attention scaling with canonical cuewise modulation so learner updates follow:
- `Delta theta_t = beta * (A_t odot x_t) * delta_t`
- where `A_t in [0,1]^n` and `x_t in R^n`
