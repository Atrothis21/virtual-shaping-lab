# V2.17.5 Usability Acceptance Checklist

## Purpose
Closeout checklist for first-open usability simplification delivered in V2.17.5.

## Release Scope
- launcher-first first-open experience
- preset-first quick-success path
- guided builder framing with progressive disclosure
- action hierarchy cleanup
- continuity/recovery improvements
- builder lazy-load performance behavior

---

## A) First-Open Simplicity Acceptance

- [x] Opening `/ui/index.html` lands on launcher-first home route.
- [x] First-open shows exactly two intent cards:
  - [x] `Run a preset` (dominant)
  - [x] `Build an experiment` (secondary)
- [x] Featured preset section present and capped (max 4).
- [x] Recent activity strip present and capped (max 3).
- [x] Recent activity ordering is deterministic and most-recent-first.
- [x] No dense lifecycle panels shown by default on first-open.

Evidence:
- `tests/v2_11_guards/test_ui_first_open_launcher_contract_guard.py`
- `tests/test_ui_launcher_intent_flow_scaffold.py`
- `tests/test_ui_recent_activity_cap_scaffold.py`
