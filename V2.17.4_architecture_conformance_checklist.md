# V2.17.4 Architecture Conformance Checklist

## Purpose
Provide explicit audit evidence that V2.17.4 UI work conforms to the intended architecture boundaries before V2.17 closeout.

## Audit Scope
- Route containers vs presentational/shared primitives
- Service and workflow responsibility boundaries
- Selector/adapter-driven view modeling
- Shared error/constraint/mismatch state presentation

## Checklist

### 1) Container/Presentational Boundaries
- Status: `PASS`
- Criteria:
  - route containers orchestrate route behavior and pass props to shared primitives
  - shared primitives render state/constraint/mismatch UI
- Evidence:
  - route containers: `virtual_shaping_lab/ui/js/react/routes/*.jsx`
  - shared primitives: `virtual_shaping_lab/ui/js/react/ui_primitives.jsx`
  - route split guard: `tests/test_ui_route_component_files_scaffold.py`

### 2) Service/Hook Responsibility Split
- Status: `PASS`
- Criteria:
  - API/network side effects are isolated behind service/workflow modules
  - route components avoid direct request implementation logic
- Evidence:
  - services/workflows:
    - `virtual_shaping_lab/ui/js/react/catalog_bootstrap_service.js`
    - `virtual_shaping_lab/ui/js/react/plan_workflow_service.js`
    - `virtual_shaping_lab/ui/js/react/preset_action_service.js`
    - `virtual_shaping_lab/ui/js/react/run_report_workflow_service.js`
  - API client boundary:
    - `virtual_shaping_lab/ui/js/react/api_client.js`
  - architecture contracts:
    - `virtual_shaping_lab/ui/js/react/ui_architecture_contracts.js`

### 3) Selector/Adapter Usage
- Status: `PASS`
- Criteria:
  - complex route rendering decisions are normalized through selector/view-model/adapter modules
  - builder form rendering uses schema/view-model adapters
- Evidence:
  - `virtual_shaping_lab/ui/js/react/lifecycle_view_models.js`
  - `virtual_shaping_lab/ui/js/react/preset_read_models.js`
  - `virtual_shaping_lab/ui/js/react/builder_form_schema.js`
  - `tests/test_ui_architecture_contracts_scaffold.py`
  - `tests/test_ui_builder_submission_guards_scaffold.py`

### 4) Shared Error/Constraint/Mismatch Components
- Status: `PASS`
- Criteria:
  - constraint and route state surfaces use shared primitives instead of route-local one-offs
  - mismatch and recovery messaging follows documented behavior across routes
- Evidence:
  - shared components:
    - `ConstraintStateChips`
    - `ConstraintMessage`
    - `RouteStatePanel`
    - `buildCatalogMismatchBanner`
  - source: `virtual_shaping_lab/ui/js/react/ui_primitives.jsx`
  - route usage: `virtual_shaping_lab/ui/js/react/routes/run_route.jsx`, `virtual_shaping_lab/ui/js/react/routes/report_route.jsx`, `virtual_shaping_lab/ui/js/react/routes/builder_route.jsx`
  - behavior docs:
    - `docs/ui_error_handling_matrix.md`
    - `docs/ui_constraint_behavior.md`
    - `docs/ui_version_mismatch_behavior.md`
