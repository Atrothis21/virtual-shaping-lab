# V3.21.5 Plan - Executable Protocol Operators and Bundle Core

## Objective
Implement executable protocol operators and a canonical bundle execution path for:
- `Omega_emission`
- `Omega_consequence`
- `Omega_advance`
- `Omega_stop`

Keep strict protocol-agent separation:
- protocol/environment computes emission/consequence/time/stop
- agent computes prediction/policy/learning internals only
